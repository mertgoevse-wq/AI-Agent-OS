# AGENT REGISTRY
## Overview
The Registry (`agents/registry.yaml`) defines all active agents grouped by their swarms.
## Active Swarms
- **Architecture**: System, Software, Infrastructure.
- **Engineering**: Backend, Frontend, API, DevOps.
- **AI**: AI Researcher, ML Engineer, Prompt Engineer, Agent Designer, RAG Specialist.
- **Automation**: Workflow Engineer, Tool Integration, MCP Specialist.
- **Quality**: Security, QA, Performance.
- **Product**: UX Designer, Documentation, Product Manager.
