# Claude Desktop Integration for OMNI-Agent-OS

This directory contains the integration configuration and documentation for connecting Claude Desktop to the OMNI-Agent-OS via the Model Context Protocol (MCP).

## Purpose
The OMNI-Agent-OS acts as the central orchestration brain for your local agent ecosystem. By connecting Claude Desktop to OMNI, you allow Claude to discover, load, and interact with the standard `omni_library` of agents, skills, and prompts.

## Contents
- `claude_config_example.json`: An example configuration file to copy into your Claude Desktop application data folder.
- `OMNI_USAGE.md`: Instructions for the end user on how Claude will interact with OMNI tools.
